# Route by failure stage: what was happening when it failed

The companion to `symptom-index.md`, split out so that each page stays under the per-file size limit.
Read this page when the report says *where* it died (startup, load, capture, first request, mid-serve)
rather than quoting a message; the symptom-phrase table with its verified class and fix is
`symptom-index.md`, and the detail pages in this topic carry the mechanism and the checked evidence.
